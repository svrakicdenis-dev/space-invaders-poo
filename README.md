# Space Invaders - Projet POO

Version orientée objet du jeu **Space Invaders** développée en Python avec la bibliothèque Pygame.

## Installation des dépendances

1. Cloner le dépôt :
```bash
git clone [https://github.com/svrakicdenis-dev/space-invaders-poo.git](https://github.com/svrakicdenis-dev/space-invaders-poo.git)
cd space-invaders-poo
```

2. Installer les dépendances nécessaires :
```bash
pip install -r requirements.txt
```

## Lancement du jeu

Exécuter le programme depuis la racine du projet :
```bash
python main.py
```

## Commandes pour jouer

- **Flèche Gauche / Flèche Droite** : Déplacer le vaisseau
- **Espace** : Tirer
